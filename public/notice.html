━━━ 💾 달라진 저장 방식 ━━━

기존에는 드라이브에 자동으로 저장·동기화됐어요.
하지만 실시간 동기화가 원활하지 않기도 하고, 가시적으로 저장이 확인되지않는 불편함이 있었습니다.
이제는 사용자가 저장 위치를 직접 선택합니다.

• 파일 → Drive에 저장 (Ctrl+S)
구글 드라이브 "대본작업실" 폴더에 .djs 파일로 저장
같은 이름이면 덮어쓰기, 처음 저장 시 이름 선택
• 파일 → 다른 이름으로 저장 (Ctrl+Shift+S)
Drive에 새 이름으로 저장
• 파일 → 내 컴퓨터에 저장 (Ctrl+Alt+S)
.djs 파일로 바로 다운로드
• 파일 → 열기 → 내 대본 탭
각 대본 옆 [☁ Drive] 버튼으로 브라우저 저장본을 바로 Drive에 올릴 수 있어요

자동백업은 드라이브 대신 브라우저(IndexedDB)에 저장됩니다.
로그인 없이도 즉시 백업되며, 파일 메뉴 → 백업/복원에서 언제든 복원 가능합니다.

⚠️ 브라우저 캐시를 직접 삭제하거나 다른 기기·브라우저에서 접속하면 자동백업은 복원할 수 없습니다.
중요한 대본은 반드시 Drive 또는 내 컴퓨터에 별도 저장해두세요.

━━━ ⚠️ 휴지통 기능 종료 예정 ━━━

저장 구조 개편으로 인해 향후 업데이트에서 휴지통 기능이 종료될 예정입니다.

휴지통에 보관 중인 대본이 있다면 지금 내보내주세요.

① 파일 메뉴 → 대본 관리 → 휴지통 진입
② 상단 [전체 내보내기] 버튼 클릭
③ 각 대본이 .djs 파일로 저장됩니다
④ 이후 파일 메뉴 → 열기로 언제든 다시 불러올 수 있어요

종료 전 충분한 유예 기간을 드릴 예정이며, 추가 공지로 다시 안내드리겠습니다.

📢 자동저장·동기화 안정성 강화 업데이트
▶

안녕하세요, 대본 작업실입니다.
지난주 동기화 사고 이후 며칠 동안 자동저장과 구글 드라이브 연동을 집중적으로 다듬었어요.
함께 들어간 트리트먼트, 메뉴, 보안 개선까지 정리해 드립니다.

✅ 자동저장 / 구글 드라이브 안정성
• 구글 인증이 만료돼도 작업 중이면 자동으로 다시 연결돼요. 갑자기 저장이 멈추는 일이 줄어들어요.
• 자동저장 중 일시적인 권한 오류가 나도 상황에 맞게 더 정확히 처리합니다.
• 저장이 실제로 완료된 시점에만 "저장됨"으로 표시되도록 바꿨어요. (예전엔 안 됐는데 된 것처럼 보일 수 있었어요.)
• 드라이브 쪽에서 오류가 나면 실제 원인을 화면에 보여드려요. (용량 부족, 권한 만료 등)
• 화면 상단에 드라이브 연결 상태 표시가 추가돼서, 지금 동기화되고 있는지 한눈에 보여요.
• 창 크기를 바꿀 때마다 매번 자동저장되던 문제와, 저장 인디케이터가 깜빡이던 현상을 정리했어요.

✅ 백업 / 복원 강화
• 스냅샷 저장 속도가 약 10초 → 3~4초로 빨라졌어요.
• 스냅샷 목록에 씬 개수, 글자 수, 용량이 함께 표시돼요. 어느 시점인지 더 쉽게 고를 수 있어요.
• 다른 기기에서 작업한 흔적이 감지되면, 드라이브에서 불러오기 전에 현재 기기 데이터를 먼저 백업해 둬요. 실수로 덮어쓰는 위험이 줄어듭니다.
• 기기 전환으로 자동 생성되는 스냅샷은 일반 스냅샷과 분리되어 보관되고 한도도 따로 관리돼요.
• "기기 데이터가 다름" 팝업에서 "나중에 결정"을 누르면 그 세션 동안 다시 묻지 않아요.

✅ 트리트먼트 (전체 회차 보기)
• 전체 회차 보기에서 Enter로 새 항목을 만들 수 있게 됐어요.
• 줄 맨 앞에서 Backspace, 줄 맨 끝에서 Delete를 누르면 위·아래 항목과 자연스럽게 합쳐져요.
• 항목을 나누거나 합친 직후에도 커서가 정확한 위치에 그대로 머물러요.

✅ 메뉴 / 화면
• 상단 메뉴 라벨을 더 명확하게 정리하고 중복을 없앴어요.
• 도움말 메뉴에 카카오톡 문의 바로가기를 추가했어요.
• 공지사항 모달의 구조를 단순하게 바꾸고 중복 표기를 정리했어요.

🛡️ 보안
• 공용 PC 모드에서 로그아웃하면 이 브라우저에 남은 작업 데이터가 삭제되도록 개선했어요.

작은 부분이지만 매일 쓰시는 작업 흐름에 영향이 큰 변경들이에요.
불편한 점이나 어색한 동작이 있으면 오류 제출이나 문의 메일로 언제든 알려주세요.
앞으로도 안정적인 작업 환경을 위해 계속 다듬어 가겠습니다.
