서비스 소개

"대본 작업실"은 한국 드라마 작가를 위한 무료 웹 기반 대본 편집 도구입니다. 별도의 설치나 결제 없이 브라우저에서 바로 대본을 쓰고, PDF·DOCX·HWPX 형식으로 내보내며, 자신의 Google Drive에 안전하게 동기화할 수 있습니다.

씬 번호 자동 연동, 인물 관리, 트리트먼트, 자료수집, 공유 검토 링크 등 대본 작업에 실제로 필요한 기능에 집중했습니다. 데스크톱·태블릿·모바일 어떤 환경에서도 같은 작업을 이어서 할 수 있습니다.

핵심 기능

대본 에디터

씬 번호 자동 매김, 슬래시 메뉴, 블록 단위 편집과 키보드 친화적 단축키.

다중 출력

PDF·DOCX·HWPX 형식으로 한 번의 설정으로 정돈된 결과물을 내보냅니다.

구글 드라이브 연동

운영자 서버를 거치지 않고 본인의 드라이브에 직접 저장·동기화합니다.

모바일 지원

이동 중에도 같은 작품을 이어 쓸 수 있는 모바일·태블릿 레이아웃.

공유 검토

로그인 없이 열람 가능한 공유 링크로 동료·감독에게 검토를 요청합니다.

설치 없이 시작

웹 표준 기술로 빌드되어 어떤 OS·브라우저에서도 즉시 사용 가능합니다.

운영 방식

"대본 작업실"은 개인 개발자가 운영하는 비상업 사이드 프로젝트입니다. 사용료는 받지 않으며, 사이트 운영비는 페이지에 표시되는 광고로 충당합니다.

이용자가 작성한 대본 본문은 원칙적으로 이용자 본인의 브라우저와 Google Drive에만 저장됩니다. 운영자 서버에는 콘텐츠가 보관되지 않으며, 인증 정보와 공유 링크 메타데이터만 처리됩니다. 자세한 내용은 개인정보처리방침을 참고해 주세요.

개인이 운영하는 서비스 특성상 응답이나 업데이트가 다소 늦을 수 있습니다. 그래도 이용자분들이 보내주시는 의견은 모두 확인하고 반영하려 노력하고 있습니다.

기술 스택

오픈 웹 기술로 만들어진 정적 SPA입니다. React 19, Vite, Tailwind CSS, IndexedDB(로컬 저장), Supabase(인증), Vercel(호스팅)을 사용합니다. 모든 작업은 이용자의 기기에서 직접 처리됩니다.
