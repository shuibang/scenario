📷 인물 사진 · 📍 관계도 위치 저장 · 🔧 관계도 인쇄 수정
최신 ▶
인물 사진 (신규)
  • 인물 페이지에서 인물마다 사진 한 장을 첨부할 수 있어요
  • 캐스팅 참고용으로 "이 인물은 이런 느낌"을 남겨두기 좋아요
  • 첨부한 사진은 인물관계도 카드에도 함께 표시돼요
  • 사진은 대본 데이터와 함께 저장돼서 다른 기기에서도 그대로 보여요
인물관계도 위치 저장 (신규)
  • 카드를 드래그해 옮긴 위치가 그대로 저장돼요
  • 새로고침하거나 다른 문서에 갔다 와도 배치가 초기화되지 않아요
  • 배치가 엉켰을 땐 카드 자동 정렬로 다시 정돈할 수 있어요
버그 수정
  • 인물관계도를 인쇄하면 관계도가 나오지 않던 문제를 수정했어요. 이제 화면에 배치한 그대로 인쇄하거나 PDF로 저장할 수 있고, 용지 방향도 가로 / 세로 중에 고를 수 있어요 (작품별로 기억해요)
  • 파일 열기에서 파일을 골라도 첫 번째 시도에는 열리지 않던 문제를 수정했어요
  • 인터넷 연결이 불안정할 때 백업 목록이 "저장된 파일이 없어요"로 잘못 표시되던 문제를 수정했어요. 백업은 그대로 있었고, 이제 목록을 못 불러온 것인지 구분해서 알려드려요

🗒️ 메모 탭 · 📌 씬 메모 뱃지 · 🔧 인쇄 버그 수정

메모 탭 (신규)
  • 오른쪽 패널에 메모 탭이 생겼어요 (문맥 | 메모 | 체크리스트 순)
  • 현재 회차에 작성한 메모를 최신순으로 모아볼 수 있어요
  • 메모 카드를 클릭하면 해당 씬으로 바로 이동하고, 목록에서 바로 삭제도 가능해요
  • 인용한 대사나 지문이 있으면 카드에 함께 표시돼요
씬 메모 뱃지 (신규)
  • 메모가 달린 씬의 씬번호 블록 우측에 메 N 뱃지가 표시돼요
  • 뱃지를 클릭하면 해당 씬의 메모 팝오버가 열리고, 팝오버에서 내용 확인·삭제를 할 수 있어요
버그 수정
  • 브라우저 인쇄 시 인쇄 창이 두 번 열리던 문제를 수정했어요
  • 연출 작업실에서 Drive 재연결이 필요할 때 안내 문구가 더 명확하게 표시돼요

인물명 뒤 약어 지원 (신규)
  • 대사 인물명 뒤에 (V.O.), (F), (E) 같은 약어를 붙일 수 있어요
  • 입력창에 홍길동 (V.O.)처럼 타이핑하면 자동으로 접미사로 인식돼요
  • 인물 선택 드롭다운에서 약어가 포함된 형태로 확인하고 선택할 수 있어요
  • PDF, DOCX, HWP, 인쇄 출력물 모두 반영돼요
버그 수정
  • 씬헤딩 블록에서 세부장소가 제대로 인식되지 않던 문제를 수정했어요
  • PDF 생성 중 폰트 파일을 불러오지 못하면 자동으로 한 번 더 시도해요 — 일시적인 네트워크 오류로 같은 오류가 반복되던 문제를 개선했어요

  • 설치형 앱에서도 최신 버전 감지를 강화했고, 설치 앱에서 구버전 캐시가 남았을 때 재실행/재설치 안내를 추가했어요
도움말 · FAQ
  • 설치 앱에서 웹과 다른 내용이 보일 때의 원인과 해결 방법을 도움말과 FAQ에 정리해 두었어요

Dropbox 저장 (신규)
  • 파일 저장 위치에 Dropbox가 새로 추가됐어요
  • Google Drive와 별개로 Dropbox에도 현재 대본을 .djs 파일로 저장할 수 있어요
  • Dropbox에는 /대본작업실/작품명.djs 형태로 저장돼요
클라우드 저장소 선택
  • 설정에서 Google Drive / Dropbox 중 기본 클라우드 저장소를 선택할 수 있어요
  • 파일 메뉴와 모바일 메뉴에 현재 연결 상태와 저장 대상이 함께 보여요 — 어디로 저장되는지 더 분명해졌어요
  • Ctrl+S는 선택된 클라우드 저장소로 저장되고, 로컬 저장은 기존처럼 따로 사용할 수 있어요
연결 · 저장 안정화
  • Dropbox 승인 뒤 앱으로 돌아왔는데도 계속 미연결로 남던 문제를 고쳤어요
  • Dropbox 저장 전에 /대본작업실 폴더를 먼저 확인하고, 없으면 자동으로 만들어요
  • 한글 폴더명·파일명 업로드 처리를 다듬어 저장 실패가 줄었어요
  • 막연하게 "저장 실패"만 뜨지 않고, 원인에 가까운 안내가 보이도록 바꿨어요
  • Google Drive 재연결이 필요한 경우에도 더 정확한 안내 문구가 나와요
PDF 출력
  • 일부 환경에서 PDF가 아예 생성되지 않던 문제를 수정했어요
  • 트리트먼트 등 특정 출력에서만 나타나던 PDF 오류가 해소됐어요
